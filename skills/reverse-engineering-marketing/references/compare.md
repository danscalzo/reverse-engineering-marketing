# Compare mode: several subjects side by side

Use when the question is "how do X, Y and Z compare?" or "who is strongest in this market?".

## Steps
1. Pick 3-5 subjects that compete for the same buyer and area (`market-adapter.md` section 4). Say why each is in.
2. Same depth level and same filters for all (same country, active/all, same dates). Different filters = no comparison.
3. Run the 12 questions for each at the chosen depth. Parallel sub-agents are fine: one per subject, same brief, same template.
4. Build the matrix, then the reading.

## Matrix (one row per question, one column per subject)
| Question | Subject A | Subject B | Subject C | Strongest | Evidence |
|---|---|---|---|---|---|
| Active ads (country, date) | 37 | 4 | 0 (bounded) | A | lib IDs, date |
| Angle and offer | ... | ... | ... | | |
| Credibility | 4.8 (812, Google) | ... | ... | | |
| ... | | | | | |

## Reading
- Where the market is crowded (everyone says the same thing) and where there is a gap nobody covers.
- The positioning a new or client business could take to stand out, as a proposal kept apart from observations.
- What each competitor does better than the client, if a client is in the comparison (inside mode for the client, outside-in for the others).
